# ADR-0005: Collection Completion Over Edition Perfection

## Status

Accepted

## Context

A partially cataloged collection with exact edition metadata is less useful for acquisition decisions than a broadly complete collection with explicit uncertainty.

## Decision

The current priority is collection completion over edition perfection. Capture useful minimum records first, retain uncertainty, and enrich edition detail progressively.

## Consequences

- Workflows should minimize required fields.
- Unknown and uncertain values must be represented honestly.
- Review and enrichment queues become important follow-up mechanisms.
- Reports requiring edition precision must account for incomplete data.
